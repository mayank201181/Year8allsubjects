# Year 8 All Subjects

**Live:** https://year8allsubjects.vercel.app

One launcher page for Vanshika's Year 8 study dashboards (Maths, Science, English, Chinese, Spanish, Geography, and History, plus test-prep sites). Static site (no build step), installable as a PWA, deployed on Vercel.

To add or change a subject, edit the `SUBJECTS` list at the top of the `<script>` in `index.html`. An empty `url` shows the subject as "Being built".
